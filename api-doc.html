Documentación de API - Estadísticas SECOP II

Esta API expone el resumen estadístico y los hallazgos del análisis de datos masivo sobre la plataforma SECOP II. Este endpoint es ideal para integrar dashboards de inteligencia de negocios (BI) o auditoría.

Endpoint Principal

GET /api/v1/secop/stats

Respuesta Exitosa (200 OK)

El endpoint retorna un objeto JSON con las métricas clave extraídas del dataset. A continuación se detalla el esquema de respuesta.

Campo Tipo Descripción
p3_total_registros integer Número total de contratos/registros analizados en la base de datos.
p4_total_variables integer Cantidad de columnas o variables presentes en el dataset original.
p5_registros_2025 integer Número de contratos cuya vigencia o registro corresponde al año 2025.
p6_pct_pymes float Porcentaje total de contratos adjudicados a empresas clasificadas como PYMES.
p7_n_pymes integer Número absoluto de contratos adjudicados a PYMES.
p8_top10_departamentos array[object] Lista de los 10 departamentos con mayor volumen de contratos. Cada objeto contiene posicion, departamento y contratos.
p9_pos6 object Extracción directa del departamento en la sexta posición para acceso rápido.
p10_modalidad_top string Nombre de la modalidad de contratación más utilizada (ej. "Contratación directa").
p11_n_modalidad_top integer Frecuencia absoluta de la modalidad de contratación principal.
p12_top3_entidades array[object] Top 3 de las entidades que más presupuesto han ejecutado. Contiene entidad y valor_total.
p13_top5_tipos array[object] Las 5 categorías de contratos más comunes (ej. "Prestación de servicios").
p14_pct_tipo_top float Porcentaje de concentración que representa el tipo de contrato principal.
p15_anomalias array[object] Lista de contratos marcados como "anómalos" por sus montos extraordinarios. Incluye entidad, monto, objeto y la url directa al SECOP.
p16_pct_anticipos float Porcentaje de contratos que contemplan pagos por adelantado.
p16_n_anticipos integer Cantidad neta de contratos con modalidad de pago anticipado.
p17_n_obligacion_ambiental integer Número de contratos que incluyen cláusulas de obligación ambiental o postconsumo.
p18_pareto object Análisis de concentración de riqueza (Principio de Pareto). Muestra la concentración del presupuesto agrupada por contratos y por entidades.
p19_genero object Estadísticas financieras desagregadas por el género del representante legal. Incluye promedio y mediana de valor contractual para Hombre, Mujer y No Definido.
p20_anomalias_tipo array[object] Auditoría de calidad de datos. Lista los campos del dataset original que requieren transformación de tipo de dato (ej. strings que deberían ser booleanos o numéricos).
